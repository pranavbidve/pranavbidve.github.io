# Pranav Bidve — Portfolio

Dark technical portfolio for Pranav Bidve, AI/ML Engineer and Founding
AI Engineer at Qosmic AI.

The repository contains both the editable application source and a static
GitHub Pages snapshot at the repository root.

## Update the résumé

1. Replace `public/Pranav-Bidve-Resume.pdf` with the updated PDF.
2. Keep the filename unchanged.
3. Run `npm run dev`, then `npm run build` and `npm run export:pages`.
4. Commit and push the updated files.

The embedded viewer and download button will then use the new résumé.

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm test
```

When the repository is public, GitHub Pages can serve the site from the
`main` branch and repository root.
